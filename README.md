# AutoCAD Corner Brace 3D

This repository contains a **3D reconstruction of a metal corner brace created in AutoCAD** based on a technical drawing provided during the *Computer Aided Graphics* course.

The project demonstrates the use of **AutoCAD drafting and modeling commands** to recreate a real mechanical component using precise dimensions and technical drawing standards.

---

## Project Overview

The object modeled in this project is a **metal corner brace**, commonly used to join wooden or structural elements at a 90° angle.

The component was recreated using AutoCAD by following the dimensions and details provided in the technical drawing.

The drawing includes:

- orthographic views
- dimensions
- hole positioning
- technical annotations

This project was developed as part of the **Computer Aided Graphics (CAG)** course at the **Technical University of Cluj-Napoca**.

---

## Object Description

The modeled object is an **L-shaped metal bracket** made of galvanized steel.

It contains multiple screw holes used for fastening structural elements.

Main characteristics:

- Length: **70 mm**
- Width: **30 mm**
- Height: **41 mm**
- Hole diameters: **Ø2.5 mm and Ø6.5 mm**
- Material: **Galvanized steel**
- Drawing scale: **1:1**

## AutoCAD Commands Used

The following AutoCAD commands were used to recreate the model:

- `Line`
- `Polyline`
- `Circle`
- `Offset`
- `Fillet`
- `Trim`
- `Copy`
- `Move`
- `Dimension`
- `Text`

These commands were used to construct the geometry, create the holes, add dimensions, and finalize the technical drawing.
